# 3D Models for Login Screen

- **KingDice.glb** – Combined dice + crown model (used on login screen)

**Colors in Blender:** React Native cannot load image textures from GLB. For colors to show in the app, use **vertex colors** or **solid base color** in Blender—no Image Texture node on Base Color. Use Principled BSDF with a single Color value, or Vertex Color.
