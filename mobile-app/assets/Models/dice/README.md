# Dice model assets

Use the combined GLB:

1. Copy `E:\King Dice\public\Models\KingDice.glb`
2. Paste to `E:\King Dice\mobile-app\assets\Models\KingDice.glb`

**Colors (Blender export):** React Native cannot load image textures from GLB. For colors to show, use **vertex colors** or **solid base color** in Blender (no Image Texture node on Base Color). Use Principled BSDF with a single Color value, or Vertex Color.
